# Toddler Activity Board

All the files you'd need to 3D print the components, program the hardware, and order the exact PCB I used.

## Some project specifications:

### Hardware
- ESP32 Dev Module

### 3D Printing
- Bambu Lab A1 using standard PLA filament

### Screws
- I used a few different sized screws which I sourced from this lot https://www.amazon.com/dp/B089QX453K?ref=ppx_yo2ov_dt_b_fed_asin_title

### Power Supply
- 4 AA Batteries held inside a battery pack providing ~5V DC to the ESP32 module
